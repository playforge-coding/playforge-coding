## Block-based programming, amplified

AmpMod is a block-based programming language built off TurboWarp that adds many small but meaningful features to make it even better, such as first-class lists, case sensitivity, and custom extensions.

With AmpMod, you can create games, animations, art, and more quickly by dragging blocks instead of manually typing everything out.

:clipboard: Arrays: Store data in your projects
:jigsaw: New blocks: Switch/case and more
:busts_in_silhouette: Community: Many features will be coming soon to enhance the community!

We also have a growing community making great projects! We're a small site, and we want you to join. If you join, please share your invite link with others to help AmpMod grow!
